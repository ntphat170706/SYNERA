khóa kỳ, phiếu điều chỉnh.

4. Quy tắc làm việc nhóm
 Git: nhánh main (ổn định), develop, và feature/<người>-<tên màn hình>. Mỗi PR nhỏ (một màn
hình), người khác review trước khi merge.
 Hợp đồng API trước khi code: thống nhất với nhóm backend một file OpenAPI (hoặc bảng API ở mục
9 của tài liệu thiết kế). Sinh type TypeScript từ đó; FE code trên MSW trước.
 Quy ước chung: component PascalCase, hook bắt đầu bằng use; tiền luôn qua formatMoney; số lượng
luôn kèm đơn vị (thùng/lốc) để tránh nhầm; số lớp 1 gắn nhãn "Tạm tính, cập nhật lúc hh:mm".
